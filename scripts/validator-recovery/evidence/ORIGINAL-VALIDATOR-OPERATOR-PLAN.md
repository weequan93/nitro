## 第一步：现在可执行，只读核查

脚本 `inspect-remote-validator.py` 仅依赖 Python 3 标准库。Docker 查询使用现有本机权限；
无需安装软件、重启 Docker 或改变权限。若节点不是 Docker 部署，告知进程管理方式，
可以先仅用 `--config` 核查明确指定的节点配置；Docker 不可用会记为错误，不启动任何服务。

将脚本保存到负责人选定的普通工作目录，在该目录执行。不要在数据库目录写报告。

### 不知道容器名时

```bash
python3 inspect-remote-validator.py --out "original-node-list-$(date +%Y%m%d-%H%M%S).json"
```

输出会列出容器名、镜像与运行状态。仅选择实际的原 validator。

### 知道容器名后

以下两行中的提示会要求输入真实容器名，不要输入私钥或密码：

```bash
read -r -p '原 validator 容器名: ' ORIGINAL_VALIDATOR
python3 inspect-remote-validator.py --container "$ORIGINAL_VALIDATOR" --out "original-node-detail-$(date +%Y%m%d-%H%M%S).json"
```

若负责人知道节点 JSON 配置在宿主机上的确切位置，可一并核查：

```bash
read -r -p '宿主机上的节点 JSON 配置路径（不是密钥文件）: ' ORIGINAL_CONFIG
python3 inspect-remote-validator.py --container "$ORIGINAL_VALIDATOR" --config "$ORIGINAL_CONFIG" --out "original-node-config-$(date +%Y%m%d-%H%M%S).json"
```

脚本只输出固定配置字段与启动日志中的公开账户地址，不输出原始日志、完整命令、环境变量、
RPC URL、密码、私钥、钱包路径或认证证书。不会打开 keystore，不联网查询链或发送交易。
报告文件权限为 0600，不覆盖旧报告。脚本测试过敏感字段筛选，但本机尚未运行远端核查。

### 回传内容

1. 上述筛选后的 JSON 报告。
2. 签名方式：本地加密 keystore、配置内私钥、外部签名器或硬件钱包。只说明类别。
3. 节点是否同时提供 RPC/同步等重要业务，以及原账户是否还被其他进程用于发送交易。
4. 是否允许在原机器运行独立测试进程，以及是否已有可隔离的测试数据库副本。

缺失启动日志、空 account 或缺少 password 配置均不等于账户不可用，也不能证明空密码。
配置声明不能替代命令行、环境和入口脚本解析后的实际运行状态。

## 第三步：原 validator 自动提交验收（核查后确定部署方式）

优先保持密钥所在位置不变。有两条可选方式，按部署能力确定：

1. 原机器运行隔离的测试 validator，使用一致且独立的测试数据库和专用 fork 连接。
   同步/RPC 生产进程保持运行；测试端口、目录、日志、父链和账户选择全部独立。
2. 演练机器保留测试 validator，原机器提供受限制的外部签名通道。
   本仓库存在 `node.staker.data-poster.external-signer` 实现，但尚未核验对方实际镜像
   和签名器协议；不能直接将它称为已可用。通道必须限制 chainId、账户、目标、调用与
   value/费用，验证签名结果，通过私有认证连接，绝不使用无约束公共签名服务。

如果两种方式暂时都不具备条件，只完成原账户签名与合约调用验收，明确保留
“原validator自动提交未验收”，不得以脚本签名冒充节点自动提交。

### 自动提交通过标准

- 测试数据库与生产数据库隔离；连接的 fork、Rollup、WASM 和候选检查点均按该次清单核验。
- 新进程启动记录的 txSender/actingAsWallet 符合预期；没有使用 Anvil 模拟身份代替签名。
- 节点使用新 WASM 验证恢复检查点之后的可用消息。
- 真实节点构造并签名普通质押/断言交易；回执 status=1，发送人为原账户。
- 普通确认路径推进 latestConfirmed；相关 NodeCreated/NodeConfirmed 及 Outbox 状态一致。
- 保存交易哈希、回执、验证终点、版本和配置筛选报告，不保存密码或明文私钥。

历史 fork 的可用数据有边界，不能靠挖空块补出真实后续批次。已有18549演练已经
resume并确认普通节点42887，不应假设它仍处于最初 paused42886。
